functionMethodology (Reliability Blender v2)

Score = 100 × (0.45×crowd + 0.25×cpoPrior + 0.20×size + 0.10×freshness) − penalties
crowd   = decay-weighted (hl=10d), fraud-adjusted, Wilson 95% CI shown
cpoPrior= per-CPO prior (Assure 0.98 only if assure=true AND stalls≥6; EA 0.78; single-generic 0.68…)
size    = redundancy: 12+→0.97, 8+Assure→0.98, 6+Assure→0.96, 4→0.84, 2→0.74, 1→0.55
fresh   = report volume: ≥100→1.0, ≥40→0.92, ≥15→0.8, ≥5→0.65, else 0.45 (low-confidence flag)
penalties: raw fail≥28% (n≥10) −12pts + RED CARD (queue-escalated: ≥25% + HIGH queue also RED); ≥20% −6pts; 1-stall+fail≥25% −5pts; worst-connector −8/−4.
queue   = separate risk (low/med/high + p50/p90 mins), never folded into Score silently.
There is no 100%-real-time offline. Provenance + hash + updated + nextRefresh on every score.
